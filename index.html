O que é display flex?

O display: flex (Flexbox) é uma propriedade CSS que cria um contêiner flexível, organizando automaticamente elementos filhos em linha ou coluna

O que é justify-content?

O justify-content é uma propriedade CSS do Flexbox e Grid usada para alinhar e distribuir o espaço entre os itens ao longo do eixo principal (horizontal por padrão, ou vertical se flex-direction for column)

O que é aling-items?

align-items é uma propriedade CSS fundamental do Flexbox e Grid usada para alinhar itens no eixo transversal (perpendicular ao eixo principal) de um contêiner
